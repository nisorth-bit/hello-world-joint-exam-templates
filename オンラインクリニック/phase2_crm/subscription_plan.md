# サブスク・3ヶ月プラン設計

作成日：2026-05-20

> 目的：都度課金から定期管理モデルへ移行し、LTV（顧客生涯価値）を高める。未病・予防領域は1回診療では収益が立たない。

---

## 基本設計方針

| 原則 | 内容 |
|---|---|
| 定期受診の自然化 | 「続けることで効果が出る」を患者が納得した上でプランに入る |
| 管理コストの明確化 | 何が含まれるかを明示（診療回数・スコア管理・フォローアップ） |
| キャンセル容易 | 継続強制は信頼を損なう。いつでも停止できることを前面に出す |
| フェーズ段階導入 | Phase 1は都度課金のみ。Phase 2からプランを導入 |

---

## プラン構成案

### ①都度課金（Phase 1から）

| 項目 | 内容 |
|---|---|
| 料金 | 診療費＋処方料（保険/自由診療に準ずる） |
| 対象 | 全患者 |
| 特徴 | シンプル。来院の都度決済 |

---

### ②3ヶ月フォロープラン（Phase 2から）

| 項目 | 内容 |
|---|---|
| 料金 | 月額XX,000円（3ヶ月一括または月払い） |
| 含まれるもの | 診療3回分 + 月次スコア管理 + フォローアップメール/LINE + 医師向けサマリー |
| 対象ピラー | 睡眠 / 男性更年期 / 女性更年期（各ピラーで料金設定） |
| 期間 | 3ヶ月（延長可能） |
| キャンセル | いつでも停止可。残余診療回数分を返金 |

**プラン訴求ポイント**
- 「毎回予約するより楽」
- 「スコアの変化が見えて治療の効果を実感しやすい」
- 「医師が経過を把握した上で診察するので診療がスムーズ」

---

### ③検査パッケージ付きプラン（Phase 2〜3）

| パッケージ | 対象ピラー | 含む検査 |
|---|---|---|
| 睡眠・疲労パネル | 睡眠 | HbA1c・鉄・フェリチン・ビタミンD・甲状腺 |
| 男性ホルモンパネル | 男性更年期 | 総テストステロン・LH・FSH・SHBG・PSA・血算・代謝系 |
| 女性更年期パネル | 女性更年期 | E2・FSH・LH・AMH・甲状腺・鉄・ビタミンD |
| SAS簡易検査 | 睡眠 | パルスオキシメーター貸し出しまたは自費HSAT |

**検査パッケージの役割**
1. 診断精度向上（テストステロン低値の確認など）
2. 継続動機の強化（数値が改善すると継続意欲が上がる）
3. 収益性向上（検査料は診療料と別立て）

---

## 料金設定の考え方

> 価格は競合・保険点数・薬剤費を踏まえて設定すること。以下は参考レンジ。

| プラン | 参考月額レンジ |
|---|---|
| 都度診療（自由診療） | 3,000〜8,000円/回 |
| 3ヶ月フォロープラン | 8,000〜15,000円/月 |
| 検査パッケージ（別途） | 15,000〜40,000円/セット |

※ 保険診療の場合は上記とは別に保険点数が適用される

---

## 解約・返金ポリシー設計

| 状況 | 対応 |
|---|---|
| プラン途中の停止 | 未使用診療回数 × 単価を返金 |
| 医師の都合による診療不能 | 全額返金 or 別医師に引き継ぎ |
| 副作用・体調悪化 | 通常診療として対応。プランの一時停止可 |

---

## KPI設計

| 指標 | 目標（Phase 2開始6ヶ月後） |
|---|---|
| プラン加入率（初診後） | 30%以上 |
| 3ヶ月継続率 | 70%以上 |
| 延長率（3ヶ月→6ヶ月） | 40%以上 |
| 月次スコア提出率 | 60%以上 |

---

## Phase別実装ロードマップ

| フェーズ | 実装内容 |
|---|---|
| Phase 1 | 都度課金のみ。プランの枠組みを設計・テキスト化しておく |
| Phase 2 | 3ヶ月プランを開始。支払いはStripe等の決済サービス活用 |
| Phase 2後期 | 検査パッケージを追加。結果管理をマイページに統合 |
| Phase 3 | 保険診療の定期管理プログラム（生活習慣病管理料等）との組み合わせ検討 |
