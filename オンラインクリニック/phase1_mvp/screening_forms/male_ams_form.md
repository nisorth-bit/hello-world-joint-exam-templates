# 男性更年期問診フォーム設計——AMSスコア

作成日：2026-05-20

> 目的：AMS（Aging Males' Symptoms）スコアで男性更年期（LOH症候群）の症状を定量化し、受診動機の強化と初診時の情報提供を行う。

---

## フォーム構成

```
Step 1：基本情報（3問）
Step 2：AMSスコア（17問）
Step 3：生活習慣・既往歴（5問）
Step 4：スコア結果表示 → 受診誘導
```

---

## Step 1：基本情報

| # | 質問 | 形式 |
|---|---|---|
| Q1 | 年齢 | プルダウン（30代〜70代以上） |
| Q2 | 身長・体重 | テキスト入力（BMI計算用） |
| Q3 | 現在、医療機関で治療中の病気はありますか？ | はい / いいえ（「はい」の場合は内容を任意記入） |

---

## Step 2：AMSスコア（Aging Males' Symptoms Scale）

各質問：1〜5点（症状なし＝1 / 軽度＝2 / 中等度＝3 / 重度＝4 / 非常に重度＝5）

### 心理・精神症状（Psychological）
| # | 質問 |
|---|---|
| Q4 | 全体的な調子が悪い（健康状態の低下、何となく体の具合が悪い） |
| Q5 | 関節や筋肉の痛み（腰痛、関節痛、手足の痛み、背中の痛み） |
| Q6 | ひどい発汗（突然のほてり、食事や運動と無関係の発汗） |
| Q7 | 睡眠の問題（寝つきが悪い、熟睡できない、早く目覚める） |

### 血管運動症状（Somatic）
| # | 質問 |
|---|---|
| Q8 | よく眠くなる、しばしば疲れを感じる |
| Q9 | いらいらする（攻撃的になる、小さなことに腹が立つ、不機嫌になる） |
| Q10 | 神経質になった（緊張しやすい、精神的に落ち着かない、じっとしていられない） |
| Q11 | 不安感（パニック状態になる） |
| Q12 | 身体的な疲労感や行動力の減退（全般的な活力の低下、活動量が少なくなった） |
| Q13 | 筋力の低下 |
| Q14 | 憂うつな気分（落ち込み、悲しみ、涙もろい、意欲の低下、気分の波、無力感） |
| Q15 | 「絶頂期は過ぎた」と感じる |
| Q16 | 燃え尽きた、どん底にいると感じる |
| Q17 | ひげの伸びが遅くなった |

### 性機能症状（Sexual）
| # | 質問 |
|---|---|
| Q18 | 性的能力の低下 |
| Q19 | 朝立ちの回数が減った |
| Q20 | 性欲の低下（セックスが楽しくない、性交への欲求が低下した） |

---

## AMSスコア解釈

| 合計点 | 重症度 |
|---|---|
| 17〜26点 | なし |
| 27〜36点 | 軽度 |
| 37〜49点 | 中等度 |
| 50点以上 | 重度 |

---

## Step 3：生活習慣・既往歴

| # | 質問 | 形式 |
|---|---|---|
| Q21 | 喫煙の有無 | 現在喫煙 / 過去喫煙 / なし |
| Q22 | 飲酒習慣 | 毎日 / 週数回 / ほとんどなし |
| Q23 | 運動習慣 | 週3回以上 / 週1〜2回 / ほとんどなし |
| Q24 | 高血圧・糖尿病・脂質異常症のいずれかがある | はい / いいえ |
| Q25 | 過去にテストステロン検査を受けたことがある | はい（結果の記憶があれば任意記入） / いいえ |

---

## Step 4：結果表示と受診誘導

### 表示ロジック

| AMSスコア | 表示メッセージ |
|---|---|
| 17〜36点 | 「現時点では症状が軽度または見られません。気になる症状があれば気軽にご相談ください。」 |
| 37〜49点 | 「中等度の男性更年期症状が見られます。テストステロン値の確認や生活習慣の改善について相談してみましょう。」 |
| 50点以上 | 「重度の症状が見られます。LOH症候群（男性更年期）の可能性があります。できるだけ早めに専門医への相談をお勧めします。」 |

---

## 注意事項

- AMSスコアは診断基準ではなく症状評価ツール。確定診断には血液検査（総テストステロン・遊離テストステロン）が必要
- うつ病など他の疾患でも同様のスコアが出ることを明記
- 結果の解釈について「このスコアだけで診断はできません」と明示
