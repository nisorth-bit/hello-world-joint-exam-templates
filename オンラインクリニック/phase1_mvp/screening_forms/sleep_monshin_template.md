## 医師側 処方判断フロー

```
いびき・無呼吸あり  → PSG検査を勧める（睡眠薬保留）
希死念慮あり       → 精神科紹介
重篤な肝疾患       → 禁忌確認（デエビゴ・ベルソムラ）
妊娠・授乳中       → 処方見合わせ

↓ 上記なし → 処方検討

基本              : デエビゴ単剤
持ち越し問題      : クービビックへ変更
不安・抑うつあり  : デエビゴ＋トラゾドン（病名：うつ状態）
更年期女性        : デエビゴ＋グランダキシン or 加味逍遥散
高齢者            : デエビゴ2.5mg or ミアンセリン
自然派・漢方希望  : ロゼレム＋酸棗仁湯

漢方選択
  イライラ強い    → 抑肝散
  疲労・眠れない  → 酸棗仁湯
  動悸・不安      → 柴胡加竜骨牡蠣湯
  更年期女性      → 加味逍遥散
  虚弱・食欲なし  → 加味帰脾湯
```
