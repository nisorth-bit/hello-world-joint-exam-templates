# 睡眠問診フォーム設計——ISI + STOP-Bang

作成日：2026-05-20

> 目的：事前スクリーニングで「不眠症候群」「睡眠時無呼吸疑い」を分類し、医師への情報伝達と受診動機の強化を同時に行う。

---

## フォーム構成

```
Step 1：基本情報（2問）
Step 2：ISI（不眠重症度指数）（7問）
Step 3：STOP-Bang（睡眠時無呼吸スクリーニング）（8問）
Step 4：随伴症状（自由選択・5問）
Step 5：スコア結果表示 → 受診誘導
```

---

## Step 1：基本情報

| # | 質問 | 形式 |
|---|---|---|
| Q1 | 年齢 | プルダウン（10代〜80代以上） |
| Q2 | 性別 | 男性 / 女性 / 回答しない |

---

## Step 2：ISI（Insomnia Severity Index）

各質問：0〜4点（全くない／軽度／中等度／重度／極めて重度）

| # | 質問内容 |
|---|---|
| Q3 | 寝付くのが困難ですか？ |
| Q4 | 夜中に目が覚めますか？ |
| Q5 | 早朝に目が覚めてしまいますか？ |
| Q6 | 現在の睡眠パターンにどのくらい満足していますか？（逆転項目：満足=0点） |
| Q7 | 睡眠の問題が日中の生活（疲労感・集中力・気分など）に影響していますか？ |
| Q8 | 睡眠の問題に他の人が気づいていると思いますか？ |
| Q9 | 現在の睡眠の問題についてどのくらい悩んでいますか？ |

**スコア解釈**
- 0〜7点：臨床的に問題なし
- 8〜14点：軽度の不眠
- 15〜21点：中等度の不眠
- 22〜28点：重度の不眠

---

## Step 3：STOP-Bang

各質問：はい（1点）/ いいえ（0点）

| 記号 | 質問 |
|---|---|
| S（Snoring） | いびきをかくと言われますか？ |
| T（Tired） | 日中に眠くなることがよくありますか？ |
| O（Observed） | 睡眠中に呼吸が止まると言われたことがありますか？ |
| P（Pressure） | 高血圧がありますか、または治療を受けていますか？ |
| B（BMI） | BMI 35以上ですか？ |
| A（Age） | 50歳以上ですか？ |
| N（Neck） | 首周りが40cm以上ですか？（男性：43cm、女性：41cm） |
| G（Gender） | 男性ですか？ |

**スコア解釈**
- 0〜2点：低リスク
- 3〜4点：中リスク
- 5〜8点：高リスク（睡眠時無呼吸の可能性が高い）

---

## Step 4：随伴症状チェック（複数選択可）

- 日中の強い眠気
- 起床時の頭痛
- 集中力・記憶力の低下
- 気分の落ち込み・不安感
- 夜間頻尿（トイレで目が覚める）

---

## Step 5：結果表示と受診誘導

### 表示ロジック

| ISI | STOP-Bang | 表示メッセージ |
|---|---|---|
| 8〜14 | 0〜2 | 「軽度の不眠の可能性があります。生活習慣の改善と合わせて、一度ご相談ください。」 |
| 15〜28 | 任意 | 「中〜重度の不眠の可能性があります。早めに専門医への相談をお勧めします。」 |
| 任意 | 3〜4 | 「睡眠時無呼吸の可能性が中程度あります。専門的な検査をご検討ください。」 |
| 任意 | 5〜8 | 「睡眠時無呼吸の可能性が高い状態です。できるだけ早めにご相談ください。」 |

### CTAボタン
- 「オンライン診療を予約する」→ 予約プラットフォームURL
- 「もう少し考えたい」→ LINEお問い合わせ / メールマガジン登録（Phase 2）

```
STOP-Bangスコア: X点（リスク: ○○）
随伴症状: ○○, ○○
年齢: XX代　性別: ○
```

---

## 注意事項

- ISIおよびSTOP-Bangは診断ツールではなく参考スクリーニング
- 結果はあくまで「受診の参考」であり、医師による診断ではない旨を明記
- 個人情報の取り扱いについてプライバシーポリシーへのリンクを設置
