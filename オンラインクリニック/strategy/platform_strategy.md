# プラットフォーム戦略——既存活用と自作の切り分け

作成日：2026-05-20  
更新日：2026-06-07（睡眠外来主軸に戦略改定）

## 基本方針

> 診療インフラは既存プラットフォームを利用。集客・問診・UX・継続フォローは自作。

フル自作は避ける。理由：本人確認・ビデオ通話・電子処方箋・薬局連携・セキュリティ等の医療インフラを最初から作ると、医療事業かSaaS開発か分からなくなる。最初は「どの入口がCVするか」「どの薬剤・検査が継続するか」の検証が先。

---

## 戦略改定の背景

**2026年6月1日：「睡眠障害」が標榜診療科に追加（医療法施行令改正）**

- 日本睡眠学会が2025年4月に厚労省へ標榜追加を要望
- 2026年1月医道審議会で審議、3月に正式了承、6月1日施行
- 平成20年以来18年ぶりの改正
- 標榜形式：「内科(睡眠障害)」「精神科(睡眠障害)」等、主診療科との組み合わせ表記

この流れを受け、睡眠医療への社会的注目・患者需要が急速に高まると判断。
**オンライン睡眠外来を主軸**に絞り、集客・コンテンツ・問診を睡眠特化で再構築する。

## 診療領域の優先順位

| 領域 | 位置づけ | Phase1での扱い |
|---|---|---|
| 睡眠外来（不眠症・OSA・CBT-I） | **主軸** | フル展開 |
| 男性更年期（LOH症候群・TRT） | サブ領域（将来復活候補） | 保留 |
| 女性更年期（HRT・更年期外来） | サブ領域（将来復活候補） | 保留 |

三本柱を同時に打つと「何の外来か」がぼやける。睡眠で認知を取ってからサブ領域を追加する。

## 既存プラットフォームを使う部分

| 機能 | 理由 |
|---|---|
| オンライン診療システム | 予約・ビデオ・決済・処方箋・薬局連携が整備済み |
| 電子カルテ / レセコン | 保険診療は既存一択。自作は重すぎる |
| 薬局連携 / 配送 | 初期は院外処方＋薬局配送。院内処方は売れ筋確認後 |

- CLINICS（メドレー）
- curon（MICIN）
- SOKUYAKU
- デジスマ診療
- YaDoc

## 自作する部分（差別化ポイント）

### 1. 集客サイト・SEOメディア（睡眠特化）
睡眠ブログ72本を核に、不眠症・睡眠時無呼吸・CBT-I・睡眠衛生の記事群を自前で保有。
既存プラットフォーム内に載せるだけではブランド資産が貯まらない。
→ `content/drafts/sleep/` の72本をPhase1で順次公開

男性更年期・女性更年期ブログ（計80本）は `blog-site/src/content/blog/_unpublished/` に保留。

### 2. 事前問診・スクリーニング（睡眠特化）
→ `phase1_mvp/screening_forms/` 参照

| 問診種別 | 対象 | Phase1 |
|---|---|---|
| 睡眠問診（ISI・STOP-Bang） | 不眠症・睡眠時無呼吸 | **優先** |
| PHQ-9 / GAD-7 | うつ・不安のスクリーニング（睡眠との鑑別） | **優先** |
| AMSスコア | 男性更年期（LOH症候群） | 保留 |
| SMI（簡略更年期指数） | 女性更年期 | 保留 |
| MHT / ピル禁忌確認 | HRT・低用量ピル処方前 | 保留 |
| 健診結果アップロード | 検査値レビュー | 保留 |

### 3. CRM・継続フォロー
不眠症は再診・CBT-I継続が収益の核。1回診療では成立しない。
→ `phase2_crm/` 参照

### 4. 検査パッケージ導線（睡眠特化）

**Phase 1は最小限。検査は収益より信頼性のためと割り切る。**

| 検査 | 目的 | Phase1 |
|---|---|---|
| 睡眠時無呼吸簡易検査（パルスオキシメーター等） | OSAスクリーニング・CPAP導入判断 | 手動運用で対応 |
| 肝機能（AST/ALT） | ベンゾ・睡眠薬処方前の安全確認 | 必要時のみ |
| HbA1c・脂質 | 生活習慣病合併の把握 | 保留 |

## フェーズ別構成

### Phase 1：最短検証（睡眠外来特化）
**目標**：睡眠需要の検証。システム完成ではない。

```
睡眠特化LP + 睡眠SEO記事 + 睡眠問診フォーム
  ↓
予約・診療・決済：既存オンライン診療システム
  ↓
処方：院外薬局（睡眠薬・CBT-Iアプリ処方）
検査：睡眠時無呼吸簡易検査を手動運用
```

### Phase 2：勝ち筋が見えたら半自作
追加：会員登録・ISIスコア経時記録・再診導線・CBT-Iプログラム管理・メール/LINEフォロー・サブスク/CBT-Iコース管理。
男性更年期・女性更年期を追加するかどうかもこのタイミングで判断。

### Phase 3：規模が出たら一部内製化
予約・決済・患者マイページ・医師管理画面・薬局API・検査連携・院内処方配送。完全自作は月間診療件数が大きく増えてから。
