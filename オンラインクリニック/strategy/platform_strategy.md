# プラットフォーム戦略——既存活用と自作の切り分け

作成日：2026-05-20

## 基本方針

> 診療インフラは既存プラットフォームを利用。集客・問診・UX・継続フォローは自作。

フル自作は避ける。理由：本人確認・ビデオ通話・電子処方箋・薬局連携・セキュリティ等の医療インフラを最初から作ると、医療事業かSaaS開発か分からなくなる。最初は「どの入口がCVするか」「どの薬剤・検査が継続するか」の検証が先。

---

## 既存プラットフォームを使う部分

| 機能 | 理由 |
|---|---|
| オンライン診療システム | 予約・ビデオ・決済・処方箋・薬局連携が整備済み |
| 電子カルテ / レセコン | 保険診療は既存一択。自作は重すぎる |
| 薬局連携 / 配送 | 初期は院外処方＋薬局配送。院内処方は売れ筋確認後 |

**候補プラットフォーム**（`phase1_mvp/platform_comparison.md` 参照）
- CLINICS（メドレー）
- curon（MICIN）
- SOKUYAKU
- デジスマ診療
- YaDoc

## 自作する部分（差別化ポイント）

### 1. 集客サイト・SEOメディア
睡眠・男性更年期・女性更年期・PMS・いびき・疲労・代謝の記事群を自前で保有。既存プラットフォーム内に載せるだけではブランド資産が貯まらない。
→ `content/drafts/` の152本が核

### 2. 事前問診・スクリーニング
自前設計で診療効率向上＋CV率向上。
→ `phase1_mvp/screening_forms/` 参照

| 問診種別 | 対象 |
|---|---|
| 睡眠問診（ISI・STOP-Bang） | 不眠症・睡眠時無呼吸 |
| AMSスコア | 男性更年期（LOH症候群） |
| SMI（簡略更年期指数） | 女性更年期 |
| PHQ-9 / GAD-7 | うつ・不安のスクリーニング |
| MHT / ピル禁忌確認 | HRT・低用量ピル処方前 |
| 健診結果アップロード | 検査値レビュー |

### 3. CRM・継続フォロー
未病/予防領域は1回診療では収益が立ちにくい。継続管理が核心。
→ `phase2_crm/` 参照

### 4. 検査パッケージ導線
検査が収益性と信頼性の鍵。既存システムだけでは見せ方・アップセルが弱い。
- 男性ホルモン検査
- 女性更年期・甲状腺・鉄パネル
- 睡眠時無呼吸簡易検査
- HbA1c・脂質・肝機能
- ビタミンD・フェリチン

## フェーズ別構成

### Phase 1：最短検証
**目標**：需要検証。システム完成ではない。

```
自前LP + 自前SEO記事 + 自前問診フォーム
  ↓
予約・診療・決済：既存オンライン診療システム
  ↓
処方：院外薬局
検査：手動運用または提携先
```

### Phase 2：勝ち筋が見えたら半自作
追加：会員登録・症状スコア保存・再診導線・検査結果管理・メール/LINEフォロー・サブスク/3ヶ月プラン管理・医師向け問診サマリー。診療ビデオ・電子カルテは既存継続。

### Phase 3：規模が出たら一部内製化
予約・決済・患者マイページ・医師管理画面・薬局API・検査連携・院内処方配送。完全自作は月間診療件数が大きく増えてから。
