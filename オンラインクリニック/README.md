# オンラインクリニック

**睡眠外来を主軸**とするオンライン診療クリニックのコンテンツ・企画フォルダ。
男性更年期・女性更年期はサブ領域として将来復活候補。

## 戦略的背景

2026年6月1日施行：**「睡眠障害」が標榜診療科に追加**（平成20年以来18年ぶり）。
日本睡眠学会が2025年4月に厚労省へ要望し、2026年3月に正式了承。
「内科(睡眠障害)」「精神科(睡眠障害)」のように主診療科と組み合わせ標榜可能。
→ 睡眠医療への社会的注目が急速に高まるタイミング。オンライン睡眠外来への追い風。

## フォルダ構成

```
オンラインクリニック/
├── strategy/          戦略文書・事業計画
├── content/           SEOコンテンツ（ブログ原稿・バックログ）
│   ├── backlogs/      記事バックログ（睡眠73本・男性40本・女性40本）
│   └── drafts/        原稿下書き（sleep/ male/ female/）
├── phase1_mvp/        Phase1：最短検証（LP・問診・プラットフォーム選定）
├── phase2_crm/        Phase2：CRM・継続フォロー・サブスク設計
└── phase3_future/     Phase3：将来内製化検討
```

## 診療領域の優先順位

| 領域 | 位置づけ | 状態 |
|---|---|---|
| 睡眠外来（不眠症・OSA・CBT-I） | **主軸** | Phase1から展開 |
| 男性更年期（LOH症候群・TRT） | サブ領域 | 将来復活候補 |
| 女性更年期（HRT・更年期外来） | サブ領域 | 将来復活候補 |

## フェーズ方針

| フェーズ | 診療インフラ | 自作する部分 |
|---|---|---|
| **Phase1** | 既存プラットフォーム（CLINICS/curon等） | 睡眠外来LP・SEO記事・睡眠問診フォーム |
| **Phase2** | 既存プラットフォーム継続 | マイページ・CRM・継続フォロー・サブスク管理 |
| **Phase3** | 一部内製化 | 予約・決済・患者管理・検査連携 |

詳細は `strategy/platform_strategy.md` 参照。
