## 差別化コンセプト

**核（従来）**：**「整形外科医が語る、痛みと眠りの診療所」**

- 慢性腰痛・膝痛・術後痛の患者は睡眠障害を高率に合併する
- 精神科・神経内科には行きにくい層に訴求できる
- 「薬に頼らない睡眠改善（CBT-I）」を主軸に据えることで規制リスクを下げる
- 他の睡眠オンラインクリニックには出せない整形外科的切り口

**三本柱に広げる場合の一文**：**睡眠を中心に、男性・女性の更年期前後のつらさも、オンラインで「整理と生活介入」の窓口にする**——専門治療は婦人科・泌尿器・内分泌等への**紹介ゲート**として明確化する（診療範囲は開業前に文書で区切る）。

## STEP 4：診療コンセプトと処方方針

### 診る対象

- 不眠症（入眠困難・中途覚醒・早朝覚醒）
- 慢性痛を伴う睡眠障害（整形外科患者層）
- 睡眠薬を減らしたい人
- 仕事・育児・生活習慣からくる不眠

### 処方薬の方針

| 薬剤 | 対応 |
|---|---|
| ラメルテオン（ロゼレム） | ○ 積極的に処方可 |
| レンボレキサント（デエビゴ） | △ 慎重に（初診時の評価を丁寧に） |
| スボレキサント（ベルソムラ） | △ 同上 |
| BZ系・非BZ系睡眠薬 | △〜✕ オンライン初診は慎重に |

**主軸：薬だけでなくCBT-I（不眠の認知行動療法）を組み合わせる**

CBT-Iの要素：
- 睡眠制限法
- 刺激制御療法
- 睡眠衛生指導
- リラクゼーション

## 進め方：記事を先に考える（コンセプトと足がけ）

**法令・雇用（副業確認）は並行して最優先**だが、発信・集患の質は「記事設計が先」の方がブレない。**手順のおすすめ**は次のとおり。

1. **三本柱だけ決める**（各1行でよい）：①痛み・回復×睡眠　②CBT-I・生活リズム（非薬物）　③受診・紹介の目安（安全線）。**更年期を柱に加える場合**は `three_pillars_strategy.md` の柱定義に合わせ、**男性向け・女性向けそれぞれ「宣言記事・受診目安・睡眠接点」**を先に書く。
2. **note を核に組む**：`social_posts_draft_20.md` の 15〜20（骨子）を、それぞれ `literature_content_map.md` のテンプレ（見出し7段）に当てはめて**見出し＋終わりまでのひとこと**まで書く。ここまでできれば「何のクリニックか」が文章として成立する。
3. **X は note の抽出**：同ファイルの 1〜14 は、確定した note から短文に割り込ませてよい。**先に note 原稿があると X が楽**。
4. **文献は「ネタ帳」として参照**：70のトリビア等から**自分の言葉での論点リスト**だけ作り、転載しない。記事ごとに「参照した特集名」を自分用メモで足す。
5. **開業準備への接続**（記事が一段落したら）：料金説明・初診で聞くこと・プラットフォームのデモ検討は、この三本柱と同じ用語で書くとサイト・同意説明まで一気通貫になる。
6. **ブログ原稿の保存場所**：完成前の Markdown は **`drafts/`** にまとめる（睡眠・更年期など柱の別を問わない）。命名ルールは `drafts/README.md`。

この順だと、「先に記事を考える」と「経営のコンセプトを固める」が同じ作業になり、後から届出やシステム選定に時間をかけられる。
