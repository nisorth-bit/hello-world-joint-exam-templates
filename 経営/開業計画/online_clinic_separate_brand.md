# オンライン診療 別ブランド先行開業 戦略

更新日：2026-06-12

---

## なぜ別ブランドにするか

| リスク | 内容 | 別ブランドで回避できること |
|--------|------|--------------------------|
| 評判リスク | オンライン診療でトラブル → 将来の実クリニックへの風評 | ブランド分離で影響を遮断 |
| 規制変化リスク | オンライン診療ルール変更・処方制限強化 | 別事業として切り分けて対応 |
| 試行錯誤リスク | 診療モデルの試行 → 失敗しても将来ブランドを傷つけない | 学習コストを別ブランドに集約 |
| 将来の選択肢 | オンライン診療を売却・提携・継続と選べる | 実クリニックと紐付いていないほうが柔軟 |

---

## 開業形態の選択肢

### 選択肢A：既存プラットフォームの非常勤医師（最速・リスク最小）

| 項目 | 内容 |
|------|------|
| 手続き | 勤務登録のみ（保健所届出不要） |
| ブランド | プラットフォーム名（MeDi-Link、クリニックフォア等） |
| 収入 | 診療報酬の60〜70%受取（目安） |
| メリット | 最速で開始可能。自分のブランドリスクゼロ |
| デメリット | 自分のブランドが一切残らない。プラットフォーム依存 |
| 向いている時期 | 2026〜2027年（経験値積み・副収入として） |

### 選択肢B：自分で別名診療所を開設（推奨・中期）

| 項目 | 内容 |
|------|------|
| 手続き | 保健所へ「診療所開設届」提出 |
| ブランド | **完全に自由**（将来の実クリニックと全く別名） |
| 住所 | 自宅以外の事務所利用可物件 or 事務所型診療所 |
| 月コスト | 賃料3〜5万円（新宿・渋谷近辺の事務所利用可小テナント） |
| メリット | 自分のブランドで医療データ・患者数が積み上がる |
| デメリット | 保健所手続き・管理者兼任の要件あり |
| 向いている時期 | 2027年以降（睡眠外来の需要確認後） |

**→ 短期はA（非常勤）で経験・収益を積み、2027年にBへ移行が現実的**

## 別ブランド名の考え方

将来の実クリニック（整形外科＋皮膚科、白金・広尾エリア）とは：
- 名称を全く変える
- 専門領域を「睡眠」に特化して打ち出す
- サイト・SNSも別ドメイン・別アカウント

### 名称の方向性例

| 方向性 | 例 |
|--------|---|
| 睡眠特化 | ○○スリープクリニック、よるの睡眠外来 |
| 機能特化 | ○○オンライン内科、○○夜間診療所 |
| ブランド系 | （検討中） |

**ポイント：「クリニック」を名称に使う場合は診療所開設届が必要（保健所）**

## 選択肢Bの開設手順（別名診療所）

| ステップ | 内容 | 期間 |
|---------|------|------|
| 1 | 事務所利用可の小テナント契約（3〜5万円/月） | 1ヶ月 |
| 2 | 保健所へ事前相談（必要書類確認） | 1〜2週間 |
| 3 | 診療所開設届・管理者届の提出 | 開設10日前まで |
| 4 | 保健所立入検査（診察室・器具の確認） | 届出後2〜4週間 |
| 5 | 社会保険・支払基金への保険医療機関指定申請 | 約2〜3ヶ月 |
| 6 | オンライン診療の届出（厚労省オンライン診療研修受講） | 研修受講後即日 |

**最短で開業まで約3〜4ヶ月**

## オンライン睡眠外来 先行ブランドの位置づけ

```
2026〜2027年
　└── プラットフォーム非常勤（経験・副収入）

2027〜2028年
　└── 別名オンライン睡眠診療所 開設
　　　├── 睡眠ブログ（73本）→ SEO集患
　　　├── 更年期・男性ホルモン外来も追加
　　　└── データ・患者数を積み上げ

2029年（実クリニック開業時）
　└── オンライン診療は「別事業」として継続 or 実クリニックに統合
　　　（統合する場合は名称変更・移転届）
```
