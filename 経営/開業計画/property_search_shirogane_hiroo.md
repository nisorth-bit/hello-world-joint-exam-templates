## 探す物件のスペック

| 条件 | 内容 |
|------|------|
| エリア第1候補 | 白金台（目黒駅・白金台駅 徒歩5分以内） |
| エリア第2候補 | 広尾（広尾駅 徒歩5分以内） |
| 面積 | 40〜55坪（2診察室＋処置室2＋受付＋待合＋PT室） |
| 階数 | 2〜4F（1Fは家賃高騰。5F以上は患者が来にくい） |
| 用途 | 医療テナント（診療所登録可能な物件） |
| 優先 | **居抜き物件**（前テナントが医療機関 → 内装費大幅削減） |
| 駐車場 | 建物内不要。近隣コインPで代替可（港区は電車来院が主） |

## 物件チェックリスト（内見時）

### 法的確認
- [ ] 診療所開設が可能な用途地域・建物用途か（保健所事前確認）
- [ ] 医療ガス（酸素・吸引）の引込み可否
- [ ] 給排水の容量（処置・洗浄での使用量に対応可か）
- [ ] 換気設備（感染対策上の要件）
- [ ] バリアフリー（高齢者・車椅子患者の導線）

### 立地確認
- [ ] 最寄り駅から徒歩5分以内か
- [ ] バス路線あるか（高齢者の交通手段）
- [ ] 視認性・看板設置可か
- [ ] 競合クリニックとの距離（整形外科・皮膚科それぞれ）

### 建物確認
- [ ] 築年数・耐震基準（1981年以降の新耐震基準か）
- [ ] エレベーター有無（2F以上の場合）
- [ ] 共用部の清潔感・管理状態
- [ ] 電気容量（美容機器・医療機器で大電力が必要）
