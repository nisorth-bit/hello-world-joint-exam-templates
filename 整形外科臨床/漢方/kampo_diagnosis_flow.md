# 漢方診察・証判定フロー

> 目標：「証を完璧に診る」ではなく「虚実・寒熱の大枠を掴み、整形外科疾患に使える処方を選べる」こと

---

## 第1章 証とは何か

証（しょう）= 患者の「今この瞬間の状態」。体質＋症状を合わせた概念。

西洋医学との違い：
- 西洋医学 → 病名から治療を決める
- 漢方 → 証（状態）から処方を決める

**同じ「腰痛」でも証が違えば処方が変わる。**

---

## 第2章 証判定の3軸（八綱弁証）

```
証の判定
├── 虚実（きょじつ）：体力・抵抗力の強弱
├── 寒熱（かんねつ）：冷えているか熱があるか
└── 気血水（きけつすい）：何が滞っているか
```

---

### 軸① 虚実

最も重要。処方の根幹になる。

| | 虚証（きょしょう） | 実証（じっしょう） |
|--|-----------------|-----------------|
| 体格 | 痩せ・華奢 | がっちり・肥満傾向 |
| 体力 | 疲れやすい・声が小さい | 体力あり・声に力 |
| 顔色 | 青白い・くすんでいる | 赤ら顔・脂性 |
| 腹診 | 腹壁軟・力がない | 腹壁張り・抵抗感 |
| 便通 | 軟便・下痢傾向 | 便秘傾向 |
| 訴え方 | おとなしい・遠慮がち | 積極的・症状を強く訴える |

**整形外科での実践**
- 虚証の高齢者腰痛 → 牛車腎気丸・補中益気湯
- 実証の急性腰痛 → 疎経活血湯・大黄含有処方

---

### 軸② 寒熱

| | 寒証（かんしょう） | 熱証（ねつしょう） |
|--|-----------------|-----------------|
| 体感 | 冷えを感じる・低体温 | 熱感・のぼせ |
| 関節症状 | 温めると楽になる | 冷やすと楽になる |
| 口渇 | 少ない・温かいものを好む | 強い・冷たいものを好む |
| 尿 | 淡色・量多い | 濃色・量少ない |
| 舌 | 淡白・白苔 | 紅舌・黄苔 |

**整形外科での実践**
- 寒証の関節痛 → 桂枝加朮附湯・当帰四逆加呉茱萸生姜湯
- 熱証の関節炎（急性）→ 越婢加朮湯・防已黄耆湯

---

### 軸③ 気血水（病態の分類）

| | 気滞（きたい） | 血瘀（けつお） | 水滞（すいたい） |
|--|-------------|-------------|--------------|
| 概念 | 気の流れが滞る | 血行不良 | 水分代謝異常 |
| 症状 | 張り感・ガス・情緒不安定 | 固定した痛み・夜間増悪・青紫色 | 浮腫・めまい・頭重・天気痛 |
| 舌 | 正常〜やや暗 | 暗紫・瘀斑 | 歯痕・水滑苔 |
| 整形科場面 | 神経障害性疼痛・CRPS | 慢性腰痛・打撲後遺症 | 術後浮腫・しびれ |
| 処方 | 柴胡剤・四逆散 | 疎経活血湯・桂枝茯苓丸 | 五苓散・防已黄耆湯 |

## 第3章 四診（ししん）の実践

### ① 望診（ぼうしん）：見る

**顔色**
- 青白い → 虚証・寒証・気血両虚
- 赤ら顔 → 実証・熱証・上熱下寒
- くすんだ暗色 → 血瘀

**舌診（重要・再現性高い）**

| 所見 | 意味 |
|------|------|
| 淡紅色・薄白苔 | 正常 |
| 淡白舌 | 気血両虚・寒証 |
| 紅舌・黄苔 | 熱証・炎症 |
| 暗紫・瘀斑 | 血瘀 |
| 歯痕・腫大 | 水滞・脾虚 |
| 乾燥・亀裂 | 陰虚・津液不足 |

**体格・体型**
- 痩せ → 虚証傾向
- 肥満・むくみ → 水滞・防已黄耆湯タイプ

---

### ② 問診（もんしん）：聞く

整形外科で使える問診追加項目：

```
□ 冷えているか・温めると楽か（寒熱）
□ 天気が悪いと悪化するか（水滞→五苓散）
□ 夜間に痛みが増すか（血瘀→疎経活血湯）
□ 疲れると悪化するか（虚証→補中益気湯系）
□ 便通・食欲（脾胃の状態）
□ 月経との関連（女性・桂枝茯苓丸など）
```

---

### ③ 切診（せっしん）：触る

**脈診（基本のみ）**

| 脈の性状 | 意味 |
|---------|------|
| 浮脈（表面で触れる） | 表証・初期 |
| 沈脈（深く押さないと触れない） | 裏証・慢性 |
| 遅脈（60未満） | 寒証 |
| 数脈（90以上） | 熱証・炎症 |
| 細脈（細く弱い） | 虚証・血虚 |
| 弦脈（弦を弾くような張り） | 肝気鬱結・痛み |

**腹診（整形外科医でも取り組みやすい）**

| 腹診所見 | 処方との関連 |
|---------|-----------|
| 腹力弱・臍下不仁（臍下が柔らかく力がない） | 腎虚 → 牛車腎気丸・八味地黄丸 |
| 胸脇苦満（肋骨弓下の抵抗・圧痛） | 肝気鬱結 → 柴胡剤（大柴胡湯等） |
| 心下痞鞕（みぞおちの抵抗感） | 脾胃の滞り → 六君子湯・半夏瀉心湯 |
| 小腹急結（左下腹部の圧痛） | 血瘀 → 桃核承気湯・桂枝茯苓丸 |
| 臍周囲に拍動 | 水滞 → 苓桂朮甘湯・五苓散 |

## 第4章 整形外科症状別 証判定フロー

### 腰下肢痛・しびれ

```
腰下肢痛・しびれ
│
├─ 高齢者・冷え・夜間頻尿あり
│   └─ 腎虚　→　牛車腎気丸
│
├─ 慢性・固定した痛み・夜間増悪
│   └─ 血瘀　→　疎経活血湯
│
├─ 冷えると悪化・温めると楽
│   └─ 寒証　→　桂枝加朮附湯
│
├─ 天気・湿気で悪化・重だるい
│   └─ 水滞　→　薏苡仁湯・防已黄耆湯
│
└─ 疲れると悪化・虚証
    └─ 気虚　→　補中益気湯
```

---

### 術後管理

```
術後患者
│
├─ 食欲低下・胃もたれが前景
│   └─ 六君子湯
│
├─ 全身倦怠感・疲労が前景
│   └─ 補中益気湯
│
├─ 貧血・体力低下・創傷治癒
│   └─ 十全大補湯
│
├─ 術後浮腫・腫脹
│   └─ 五苓散
│
└─ フレイル・サルコペニア・高齢
    └─ 人参養栄湯
```

---

### 冷え・末梢循環

```
冷え・末梢症状
│
├─ 女性・月経痛・下肢しびれ
│   └─ 桂枝茯苓丸
│
├─ 極度の冷え・しもやけ様
│   └─ 当帰四逆加呉茱萸生姜湯
│
├─ 浮腫・肥満・膝痛
│   └─ 防已黄耆湯
│
└─ 天気痛・めまい・頭重
    └─ 五苓散
```

## 第5章 最初の1ヶ月でやること

### Step 1（Week 1〜2）：虚実・寒熱だけ判定する

問診で以下の2点だけ確認する：
1. 「冷えますか？温めると楽になりますか？」→ 寒熱
2. 「疲れやすいですか？食欲はありますか？」→ 虚実

### Step 2（Week 3〜4）：舌診を加える

診察のたびに舌を見る習慣をつける。
まず「淡白か、紅か、暗紫か」だけを判断する。

### Step 3（2ヶ月目〜）：腹診を加える

「臍下不仁（臍下が柔らかい）＝腎虚」だけ判定できれば牛車腎気丸の適応が分かる。
