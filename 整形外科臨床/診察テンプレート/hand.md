# 手（整形外科 診察テンプレート Oのみ）

**臨床的意義：** 手の診察は変形・神経障害・腱損傷を多角的に評価する。Kanavel徴候による化膿性腱鞘炎の早期診断と、神経障害パターン（正中・尺骨・橈骨）の識別が特に重要。

- 視診：Skin, Scar, Atrophy, Thenar/Hypothenar/IO, Deformity（SN/BH/UD/Ape/Claw/Drop）, Alignment
- Tenderness：- / +
- Swelling：- / +
- Thumb ROM：RadAbd 60/60, UlnAdd 0/0, PalAbd 90/90, PalAdd 0/0, MCP Flex 60/60, MCP Ext 10/10, IP Flex 80/80, IP Ext 10/10
- Finger ROM：MCP Flex 90/90, MCP Ext 45/45, PIP Flex 100/100, PIP Ext 0/0, DIP Flex 80/80, DIP Ext 0/0, Abd 20/20, Add 0/0
- 機能：Grip, Pinch, TAM, TPD
- 感覚：Ten test-/+ SW monofilament（緑/青/紫/赤）
- 神経：Median/Ulnar/Radial
- 特殊テスト（疑う疾患に応じて選択）
  - 尺骨神経：Froment-/- Wartenberg sign-/-（小指外転）Tinel（cubital/Guyon）-/-
  - 正中神経：Tinel（carpal tunnel）-/- Phalen-/-（必要時）
  - CMC OA：Extension-/- Adduction-/- Lever-/- Pressure-shear-/-
  - De Quervain：Finkelstein-/-
  - 屈筋腱鞘炎/感染：Kanavel-/-（①紡錘状腫脹 ②屈曲位 ③腱鞘に沿った圧痛 ④伸展時痛）Squeeze-/-
  - 側副靱帯：UCL（thumb MCP）stress-/-（必要時）
  - 内在筋拘縮：Bunnell-Littler-/-
  - 屈筋腱断裂：Sweater finger sign-/-（FDP）
  - 槌指/ボタン穴：Elson-/-（central slip）
  - 指IP：IP test-/-（必要時）

## 特殊テスト 詳細

### 1. Kanavel signs（カナベル4徴候）

**目的**：化膿性屈筋腱鞘炎（septic flexor tenosynovitis）の診断に用いる緊急性の高い所見。  
**肢位**：仰臥位または座位。  
**方法**：以下の4徴候を系統的に確認する。  
**陽性**：以下の4項目を評価する：①紡錘状腫脹（fusiform swelling of the finger）；②屈曲位安静姿勢（semiflexed resting posture）；③腱鞘に沿った圧痛（tenderness along the tendon sheath）；④他動的伸展時の著明な疼痛（pain with passive extension）。  
**示唆**：化膿性屈筋腱鞘炎。4徴候が揃えば緊急手術（洗浄・デブリードマン）の適応。各徴候の感度64〜97%。診断が疑われたら抗菌薬投与と緊急コンサルトを行う。

---

### 2. Froment sign（フロマンサイン）

**目的**：尺骨神経（ulnar nerve）麻痺による内転筋（adductor pollicis）の機能不全を評価する。  
**肢位**：座位。  
**方法**：患者に紙を母指と示指でつまむよう指示し、検者が紙を引き抜こうとする。  
**陽性**：内転筋の力が不十分なため、正中神経支配の長母指屈筋（FPL: flexor pollicis longus）を代償使用し、母指IP関節（interphalangeal joint）が屈曲してしまう。  
**示唆**：尺骨神経麻痺（cubital tunnel syndrome、Guyon管症候群）。感度90%、特異度98%と高精度。内転筋は尺骨神経深枝（deep branch of ulnar nerve）支配。

---

### 3. Wartenberg sign（ワルテンベルクサイン）

**目的**：尺骨神経麻痺による第3掌側骨間筋（3rd palmar interosseous）機能不全を評価する。  
**肢位**：座位、手掌を下（回内位）に向けた状態で指を伸展・内転させる。  
**方法**：患者が5指を完全内転位（指同士を閉じた状態）に保つよう指示する。  
**陽性**：小指が外転位に保たれ、内転できない（小指が「逃げる」）。  
**示唆**：尺骨神経麻痺（第3掌側骨間筋の機能不全）。鷲手変形（claw hand）と合わせて確認する。

---

### 4. Elson test（エルソンテスト）

**目的**：中央索（central slip）断裂を評価し、ボタン穴変形（boutonnière deformity）の早期診断に用いる。  
**肢位**：座位、PIP関節（近位指節間関節）を机の端で90°屈曲位に保持。  
**方法**：患者に中節骨（middle phalanx）を伸展させるよう指示し、検者が抵抗する。同時にDIP関節（遠位指節間関節）の硬さ（rigid extension）を確認する。  
**陽性**：PIP関節での伸展力が消失し、DIP関節が過伸展・強直する（側索が横索として機能するため）。  
**示唆**：中央索断裂。感度81%、特異度97%。急性期に陰性でも断裂を否定できない場合があり、疑わしければ固定・再評価を行う。

---

### 5. UCL stress test for thumb MCP（母指MCP UCLストレステスト）

**目的**：母指MCP関節（metacarpophalangeal joint）の尺側側副靭帯（UCL: ulnar collateral ligament）損傷（Skier's thumb / Gamekeeper's thumb）を評価する。  
**肢位**：座位、母指MCP関節0°（伸展位）および30°屈曲位。  
**方法**：検者が母指の基節骨を把持し、MCP関節に橈側方向への外反ストレスを加える。0°と30°屈曲位の両方で確認する。  
**陽性**：患側の外反動揺が健側より著明に大きい（>35°の開大、または健側比15°以上の差）。終末感がソフト・消失している場合はStener病変を考慮。  
**示唆**：UCL損傷（Skier's thumb）。Stener病変（腱膜による靭帯の解剖学的整復障害）が疑われる場合は手術適応となるため、MRI評価を考慮する。

---

### 6. CMC grind test（CMC関節グラインドテスト）

**目的**：母指手根中手関節（CMC関節：carpometacarpal joint）の変形性関節症（basal joint arthritis）を評価する。  
**肢位**：座位。  
**方法**：検者が母指中手骨を把持し、CMC関節に軸圧を加えながら回旋させる（grind）。  
**陽性**：CMC関節部に疼痛・軋轢音（crepitus）が誘発される。  
**示唆**：母指CMC関節症（basal joint arthritis of the thumb）。疼痛の部位がCMC関節に限局していることを確認し、De Quervain腱鞘炎との鑑別を行う。

---

### 7. Bunnell-Littler test（バネル-リトラーテスト）

**目的**：内在筋（intrinsic muscle）拘縮と関節性拘縮（joint contracture）を鑑別する。術前評価および治療方針決定に必須。  
**肢位**：座位、評価する指のMCP関節を伸展位に保つ。  
**方法**：①MCP関節伸展位でPIP関節を他動的に屈曲させる（内在筋を伸長した状態でPIP屈曲を確認）。②次にMCP関節を屈曲位にして同様にPIP関節を他動的に屈曲させる（内在筋を弛緩させた状態）。  
**陽性**：MCP伸展位でPIP屈曲制限あり、MCP屈曲位でPIP屈曲が改善する → 内在筋拘縮。MCP肢位によらずPIP屈曲制限が変わらない → 関節性拘縮（関節包・側副靭帯の拘縮）。  
**示唆**：内在筋拘縮（虚血性拘縮・RA・外傷後）vs 関節性拘縮の鑑別。手術適応・手術方法（内在筋切離 vs 関節包切離）の選択に直結するため術前に必ず評価する。

---

### 8. Sweater finger sign（スウェーターフィンガーサイン）

**目的**：深指屈筋（FDP: Flexor Digitorum Profundus）腱の完全断裂をスクリーニングする。  
**肢位**：座位、手関節中間位・指を自然弛緩位に保つ。  
**方法**：患者に手関節を軽度背屈させ、指の自然屈曲肢位（cascade）を観察する。正常では全指が段階的に屈曲した自然なカスケード肢位をとる。各指のDIP関節の屈曲有無を比較する。  
**陽性**：一本の指のみDIP屈曲が欠如し、他指より伸展位に飛び出している（指が「セーターから飛び出た」ように見える）。  
**示唆**：FDP腱断裂（特にzone 1〜2）。切創・ばね指手術後・スポーツ外傷（jersey finger）で生じる。DIP屈曲が完全に消失していても患者が気づいていない場合が多く、全指の確認が必要。
