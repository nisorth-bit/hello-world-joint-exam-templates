# 右中指狭窄性腱鞘炎 手術計画・記録
## 腱鞘切開術（A1 pulley 解放）

---

## サマリー

| 項目 | 内容 |
|---|---|
| 診断 | 右中指狭窄性腱鞘炎（trigger finger） |
| 術式 | 腱鞘切開術（open A1 pulley release） |
| 術者 | 木村先生・西村 |
| 麻酔 | 局所麻酔（1%キシロカイン10 mL）皮下＋腱鞘内 |
| 体位 | 仰臥位 |
| 駆血圧 | 220 mmHg |
| 皮切 | A1 pulley直上・MP関節近位の皮線に沿う斜切開 |
| Locking | 術前に明らかに確認できず |
| 縫合 | 5-0ナイロン 垂直マットレス3針＋単結節縫合 |

---

## 術前計画

### 病態評価

狭窄性腱鞘炎（trigger finger）はA1 pulleyと屈筋腱（FDP・FDS）の間に生じる狭窄と炎症性肥厚により、腱の滑走障害・弾発現象（triggering）・ロッキング（locking）をきたす疾患である。

| グレード（Quinnell分類） | 臨床所見 |
|---|---|
| Grade I | 不均一な腱の動き |
| Grade II | 弾発（triggering）あり、自動整復可 |
| Grade III | 整復に他動力が必要 |
| Grade IV | 固定屈曲拘縮（locking） |

本症例はGrade II〜IIIと考えられ、術前に明らかなlockingは確認できなかった。

### 解剖学的背景

| 構造 | 位置・特徴 |
|---|---|
| A1 pulley | MP関節掌側・中指では長さ約1.17 cm[^1] |
| A0 pulley | A1の近位、手掌腱膜より派生 |
| C0（cruciate）pulley | A1遠位端と接し、A1-A2境界の指標。掌側指皮線より約0.46 cm近位に位置[^1] |
| A2 pulley | 基節骨骨幹部。切離禁忌（bowstringing のリスク） |
| 橈側・尺側指神経 | A1 pulley両側に近接。特に橈側指神経は中指A1解放時にも損傷報告あり[^3] |

> 中指A1 pulleyは人差し指・薬指と同等の長さ（1.17 cm）を持ち、小指（0.98 cm）より有意に長い[^1]。

### 手術適応

保存療法（腱鞘内ステロイド注射）奏功しない場合に手術適応とする。開放的A1 pulley解放術はlocking・Grade III以上・ステロイド注射後再発例に推奨される[^2]。

---

## 体位・手術室配置

| 項目 | 内容 |
|---|---|
| 体位 | 仰臥位、患手を手台に外転して静置 |
| 駆血帯 | 上腕（または前腕）に装着、220 mmHg |
| 麻酔 | 1%キシロカイン10 mLを**皮下および腱鞘内**に注射 |
| 光源・拡大 | ルーペ使用推奨（ルーペ使用群で術後遷延症状12.5%、非使用群35.0%と有意差[^2]） |

## 手術手順

### Step 1：皮切マーキング・局所麻酔

1. 中指**A1 pulley直上**・MP関節より近位で**皮線に沿う斜切開**を予定する
   - 掌側指皮線（palmar digital crease）近位を基準とし、A1 pulley近位端はこの皮線と掌側手掌皮線の距離に相当する[^1]
2. **1%キシロカイン10 mL**を皮下および腱鞘内に注射する

---

### Step 2：皮切・腱鞘到達

1. **小円刃**で斜切開を行う
2. **モスキート**で腱鞘まで刃先を当て、**あらゆる方向に開く**（組織を噛まないよう内部で閉じない）
3. **神経鈎・小鈎鈎**で腱・神経などの組織を保護しながら腱鞘を展開する

> **デジタル神経の保護**：橈側指神経はA1 pulley橈側に近接し、中指においても切開・剥離時の損傷報告がある[^3]。モスキートを閉じた状態でくぐらせ、神経鈎で確認してから切開を進める。

---

### Step 3：A1 pulley 切開

1. 腱鞘直上で腱群を損傷しないよう、**腱走行方向に5 mm程度**の小切開を加える
2. **モスキートをくぐらせ**て安全な切開経路を確保する
3. **小円刃**でA1 pulleyを腱走行方向に切開する
4. 近位・遠位の切開範囲を以下のとおり設定する：
   - **近位（A0 pulley）**：できるぎりぎりまで解放する
   - **遠位（A2 pulley）**：メッツェンバウムを**骨に沿わせて**ぎりぎりまで切開し、A2 pulleyは温存する
   - C0（cruciate）pullleyが遠位切開の目安となる（掌側指皮線より約0.46 cm近位）[^1]

> **A2 pulley温存の理由**：A2 pulleyは基節骨骨幹部を覆い屈筋腱のbowstringを防ぐ最重要プーリーである。A2まで切離するとbowstringing・把持力低下の原因となる。遠位の切開はA1-A2境界を超えないよう注意する[^1][^4]。

---

### Step 4：FDP・FDS確認・滑膜切除

1. **FDP・FDS**をそれぞれ**モスキート・ゾンデ・神経鈎**で牽引・確認する
2. 腱間に付着している**滑膜**を、腱・神経を損傷しない範囲で切除する
3. 腱の滑走を確認し、**lockingがないこと**を確認する（自動屈伸・他動屈伸にて）

---

### Step 5：洗浄・閉創

1. 生理食塩水で洗浄・止血を確認する
2. **5-0ナイロン**で以下のとおり縫合する：
   - **垂直マットレス縫合**：3針
   - **単結節縫合**：針間に適宜追加
3. ドレッシングを行う

---

## 術後方針

| 時期 | 内容 |
|---|---|
| 術直後 | 軽い包帯固定・患手挙上 |
| 1〜3日 | 手指の自動運動開始（屈伸） |
| 10〜14日 | 抜糸（5-0ナイロン） |
| 術後〜 | 日常生活動作へ段階的復帰 |

> 開放的A1 pulley解放術後の症状遷延はルーペ非使用・不完全解放が主因とされ、DASH scoreの有意な改善が報告されている（術前53.07 → 術後18.41）[^2]。

## Pitfall

1. **デジタル神経損傷**：橈側・尺側指神経がA1 pulleyの両側に近接する。中指は"安全"とされるが橈側指神経neuroma形成の報告がある[^3]。モスキートを閉じたままで腱鞘に到達し、神経鈎で神経を確認・保護してから切開する。

2. **A2 pulley切離（bowstringing）**：A2まで切離すると屈筋腱のbowstringingが生じ把持力が低下する。遠位切開はC0 pulleyを遠位限界の目安とし、骨に沿ったメッツェンバウムで慎重に進める[^1]。

3. **A1 pulley不完全解放（再発）**：近位（A0）・遠位（A2手前）まで十分に解放しないと症状が再発する。特に近位のA0部での不完全解放が多い。

4. **腱損傷**：腱走行方向に沿った5 mm初期切開とモスキートを通じた確認により、FDP・FDSへの直接損傷を防ぐ。鋭利な刃が腱に直接当たらないよう操作する。

5. **術後遷延症状**：ルーペを使用しない場合に遷延症状が有意に多い（35% vs 12.5%）[^2]。必要に応じてルーペを使用する。

6. **不完全なlocking確認**：術後に他動・自動屈伸でlocking消失を確認しないと、不完全解放を見逃す可能性がある。Step 4で必ず確認する。

---

## カンファレンス用まとめ

右中指狭窄性腱鞘炎（Quinnell Grade II〜III、術前明らかなlockingなし）に対し、局所麻酔（1%キシロカイン10 mL皮下＋腱鞘内）・仰臥位・上腕駆血220 mmHgにて開放的A1 pulley解放術を施行。中指MP関節近位・皮線に沿う斜切開。モスキートを閉じたままで腱鞘まで進め、神経鈎・小鈎鈎でデジタル神経を保護しながら展開。腱走行方向に5 mm初期切開後、モスキートをくぐらせて小円刃でA1 pulleyを切開。近位はA0 pulleyぎりぎり、遠位はメッツェンバウムを骨に沿わせてA2 pulley温存しながらぎりぎりまで解放。FDP・FDS牽引・確認後、腱間滑膜を適宜切除。他動・自動屈伸でlocking消失確認。5-0ナイロン垂直マットレス3針＋単結節縫合で閉創。
