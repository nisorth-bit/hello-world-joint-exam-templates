## 術前計画

### 病態・分類評価

**多発性骨髄腫（Multiple Myeloma）骨病変　T7・T10・T11**

| 項目 | 内容 |
|---|---|
| 疾患背景 | 骨髄腫細胞の骨髄浸潤による骨破壊（厳密には"骨転移"ではなく骨髄腫骨病変） |
| 臨床的扱い | 脊椎転移性腫瘍に準じて評価：疼痛・病的骨折・不安定性・硬膜外進展・脊髄圧迫 |
| 再燃/進行評価 | IgG 4000台への上昇＋新規/増悪骨病変 → 再燃・進行として血液内科的再評価が必要 |

#### MRI 典型所見

| 所見 | 詳細 |
|---|---|
| T1 | 低信号 |
| T2FS / STIR | 高信号 |
| 造影 | 増強効果あり |
| DWI | 高信号（ADC低下傾向） |
| CT | 溶骨性変化 |

> **注意**：T2FS/STIR高信号のみではMM病変確定ではない。鑑別：新鮮圧迫骨折・変性終板炎・Schmorl結節・感染・骨挫傷・赤色髄再転換など

#### MRI 浸潤パターン分類

| パターン | 特徴 |
|---|---|
| Normal | MRI上ほぼ正常（early stage） |
| Focal | 限局性 T1低信号・T2FS/STIR高信号病変 |
| Diffuse | びまん性浸潤（広範な骨髄置換） |
| Variegated | 混合パターン |

---

### 不安定性評価：SINS（Spinal Instability Neoplastic Score）

| 項目 | 内容 | スコア |
|---|---|---|
| 部位（location） | T7：junctional（T3–T9）；T10/T11：semi-rigid | T7：2点, T10/T11：1点 |
| 疼痛（pain） | 体動時疼痛あり | 3点 |
| 骨病変の性状（bone lesion） | 溶骨性（lytic） | 2点 |
| 脊椎アライメント（alignment） | 骨折による後弯変形あり | 2点–4点 |
| 椎体圧壊（vertebral body collapse） | T11高度圧壊（>50%） | 3点 |
| 後外側要素（posterolateral involvement） | T11後方成分破壊あり | 3点 |
| **合計（推定）** | | **≥15点（Unstable）** |

**SINS解釈**
- 0–6点：Stable
- 7–12点：Potentially unstable
- 13–18点：**Unstable → 脊椎外科コンサルト必須**

> SINS はMechanical instabilityの評価。神経症状の有無（Neurologic評価）とは別軸。下肢麻痺・膀胱直腸障害がなくてもSINS高値なら脊椎外科コンサルト適応。

---

### 硬膜外進展評価：ESCC / Bilsky分類

| Grade | 定義 |
|---|---|
| 0 | 骨病変のみ、硬膜外進展なし |
| 1a | 硬膜外進展あり、硬膜嚢圧排なし |
| 1b | 硬膜嚢圧排あり、脊髄接触なし |
| 1c | 脊髄接触あり、圧迫なし |
| 2 | 脊髄圧迫あり、髄液腔は残る |
| 3 | 脊髄圧迫あり、髄液腔消失 |

> Grade 2–3 = **High-grade ESCC**。下肢症状がなくても画像上高度圧迫なら放射線治療・除圧・固定の適応を評価する。RT単独では不安定性の解決にならない点に注意。

---

### 固定範囲の設計

#### UIV / LIV の考え方

**T11 が不安定性の主体**（高度圧壊＋後方成分破壊）であり、T10・T11 をまたぐ bridge fixation を採用する。

| 項目 | 内容 |
|---|---|
| UIV | **T8・T9**（2椎体）：T7 は BKP 対象のため固定範囲から外す |
| LIV | **T12・L1**（2椎体）：T11 直下から健常椎体まで確保 |
| T10・T11 | Bridge 内に含まれる。スクリューは骨質による（セメントスクリュー or スキップ） |
| T7 | **BKP**（後壁温存確認後）：固定範囲外で独立した疼痛治療 |
| Bridge の利点 | T11の後方破壊部に直接スクリューを頼らず，上下の健常椎体で荷重を分散 |

> T8・T9 の2椎体を UIV として確保することで、T7 BKP 後に T7 が UIV 隣接椎となっても直接スクリュー依存しない構成になる。T12・L1 も2椎体確保し LIV アンカー強度を補強する。

---

### 各椎体への対応方針

| 椎体 | 病変 | 対応方針 |
|---|---|---|
| T7 | 病的骨折，**後壁温存** | **BKP**（固定範囲外・独立した疼痛治療） |
| T8・T9 | 健常（または軽微） | **UIVアンカー**（2椎体スクリュー；セメント補強検討） |
| T10 | 疼痛性圧迫骨折，後壁温存 | Bridge内でまたぐ；骨質良好ならセメントスクリュー追加も検討 |
| T11 | **不安定性の主体**：高度圧壊＋**後方成分破壊** | Bridge内でまたぐ（BKP禁忌）；スクリュー挿入困難なら T10・T12 でサポート |
| T12・L1 | 健常（または軽微） | **LIVアンカー**（2椎体スクリュー；セメント補強検討） |

---

### セメント併用スクリュー（Cement-Augmented Pedicle Screw）

#### 適応条件（本症例に該当するもの）

| 条件 | 本症例 |
|---|---|
| MM多発溶骨性病変 | ✓ |
| 骨粗鬆症相当の骨質不良 | ✓（MM浸潤＋ステロイド歴） |
| 長節固定 | ✓（T8–L1，bridge fixation） |
| UIV / LIV の把持力が不安 | ✓ |
| 術後RT・全身治療で骨癒合遅延予測 | ✓ |

#### 注意点

| リスク | 対策 |
|---|---|
| セメント漏出（硬膜外・椎間孔内） | 透視下に緩徐注入，漏出時の神経症状確認 |
| 将来の抜去困難 | 最終アンカー椎体（UIV・LIV）への使用を慎重に判断 |
| 抜釘・再固定延長時の対応 | 最初の計画段階でLIVを健常椎体まで十分延長しておく |

---

### インプラント・他術式との比較

| 術式 | 特徴 | 本症例への適用 |
|---|---|---|
| 後方固定術のみ | 不安定性解決，除圧不十分なら前方手技追加 | 第一選択 |
| 後方除圧＋固定 | High-grade ESCCで神経症状あれば追加 | 神経症状出現時に検討 |
| BKP / PVP | 後壁温存例の疼痛性圧迫骨折 | **T7：後壁温存ならBKP適応**；T11：後方破壊のため禁忌 |
| 前方手術 | 椎体置換，360°固定 | 前方圧迫高度・後路単独困難例で検討 |
| 放射線治療（RT） | 局所腫瘍制御 | 後方固定と組み合わせ；RT単独では不安定性解決せず |

---

### 注意すべき解剖・合併症リスク

| 項目 | 内容 |
|---|---|
| 胸椎椎弓根径 | T5–T7は細い（5–7 mm）；スクリュー径・角度の術前計画必須 |
| 硬膜損傷 | 後方成分破壊部（T11）での剥離に注意 |
| 出血 | MM溶骨性病変は出血多量リスク；Cell saver・術前塞栓検討 |
| セメント熱傷・漏出 | 神経根・脊髄への漏出を防ぐ |
| 術後放射線 | 固定と並行してRT計画 |

## 手術手順

### Step 1：体位・準備
腹臥位。Jacksonテーブルまたはフレーム使用。腹部フリーで静脈圧低下を図る。術中神経モニタリング（MEP/SEP）を装着。透視C-armをスタンバイ。

> セメント使用予定部位はあらかじめスクリューサイズ・注入量を計画しておく

### Step 2：後方正中切開・展開
正中切開，傍脊柱筋を骨膜下剥離。固定予定椎体（T8–L1）の横突起・椎弓根を露出。BKP施行のため T7 も展開する（または BKP を先行する場合は側臥位経皮アプローチ）。

> 出血に備えてバイポーラ・ボーンワックスを準備。MM病変部は出血傾向が高い

### Step 3：椎弓根スクリュー挿入
解剖学的ランドマーク＋透視確認でスクリューを挿入。

| 部位 | スクリュー方針 |
|---|---|
| T8・T9（UIV） | 通常スクリュー；骨質不安ならセメント補強 |
| T10 | Bridge内；骨質・椎弓根径に応じてセメントスクリューまたはスキップ |
| T11 | Bridge内；後方破壊で把持困難ならスキップ or セメントスクリュー慎重判断 |
| T12・L1（LIV） | 通常スクリュー；骨質不安ならセメント補強 |

> セメント注入は透視下に緩徐に行い，漏出確認後にスクリュー挿入。T11 の後方破壊部は把持力が期待できないため，無理なスクリュー挿入よりも隣椎アンカー強化を優先

### Step 4：除圧（必要に応じて）
Bilsky Grade 2–3の場合：椎弓切除または部分椎弓切除による除圧。
T11後方成分破壊部：不安定なラミナ・棘突起の処理。

> 神経モニタリングに注意しながら硬膜外剥離。T11は後方成分が破壊されており剥離に注意

### Step 5：T7 BKP（後壁温存例）
T7 後壁温存を CT/MRI で確認後，バルーン椎体形成術（BKP）を施行。
- 透視下両側椎弓根アプローチ
- バルーン拡張→ セメント充填（PMMA または CaP）
- 後方固定術と同セッションまたは分割施行

> T11 は後方成分破壊のため BKP 禁忌。T10 は Bridge 内で固定構造による免荷が期待できるため BKP の優先度は T7 より低い

### Step 6：ロッド設置・矯正・固定
ロッドを設置し，後弯変形を矯正しながら締結。側方ロッドも必要に応じて追加。
固定範囲内の横突起間に局所骨（＋人工骨）で骨移植。

> MMの骨癒合能は低下している。術後RTを行う場合は骨癒合さらに遅延するため，インプラントの把持力が長期にわたって求められる

### Step 7：閉創
ドレーン留置（2本）。筋膜・皮下・皮膚を閉創。

## 術後方針

| 項目 | 内容 |
|---|---|
| 離床 | 硬性 TLSO / DLSO 装着下で術翌日〜離床 |
| 装具 | 硬性胸腰椎コルセット（TLSO）；腰椎コルセット単独は不十分 |
| 荷重 | 徐重（3 weeks）→ 漸増 |
| 神経症状モニタリング | 術後24–48 h は下肢筋力・感覚・膀胱機能を定期確認 |
| 骨修飾薬 | ゾレドロン酸またはデノスマブを継続；投与前の歯科評価済みか確認 |
| 全身治療 | 血液内科と連携し，MMに対する全身治療（再燃対応）を並行 |
| RT | 局所制御目的の術後放射線治療を計画（骨融合に影響するため照射タイミングを整形外科と放射線科で協議） |
| 画像フォロー | 術後3・6・12か月でCT/MRI；スクリュー緩み・隣接椎体骨折・病変進行を確認 |
| 顎骨壊死 | 骨修飾薬継続中は歯科処置・抜歯を慎重に |

## Pitfall

1. **T11が不安定性の主体であることを見落とさない**：T11 の高度圧壊＋後方成分破壊が不安定性を規定している。T8/T9–T12/L1 の bridge fixation でT11をまたぐ設計が合理的[^1]。

2. **T11 へのBKP単独施行禁忌**：後方成分破壊を伴う高度圧壊椎体への BKP は骨折拡大・神経傷害リスクがある[^2]。必ず固定構造でまたぐ。

3. **腰椎コルセット（LSO）では不十分**：T7/T10/T11 の胸椎〜胸腰椎移行部病変には硬性 TLSO/DLSO が必要[^3]。

4. **セメントスクリューの将来的抜去困難**：再固定延長時に抜去が困難になるため，最初から LIV を健常椎体まで延長しておく[^4]。

5. **MM 再燃の見落とし**：IgG 上昇＋新規骨病変 → 全身治療変更/開始を血液内科に依頼。整形外科単独の局所治療で対応しない[^5]。

6. **骨修飾薬前の歯科評価忘れ**：ゾレドロン酸・デノスマブ開始前に歯科評価を行わないと顎骨壊死（MRONJ）リスクが上昇する[^6]。

7. **術後 RT による骨癒合遅延**：照射野内のスクリュー把持力低下・骨癒合不全を考慮し，インプラント設計（本数・セメント使用）を強化する[^7]。

## カンファレンス用まとめ

多発性骨髄腫（MM）の骨病変として T7・T10・T11 に病的骨折を認める症例。MRI では各椎体に T1 低信号・STIR 高信号・造影増強を認め，CT で溶骨性変化を伴う。SINS 評価では 15 点以上（Unstable）であり，mechanical instability として脊椎外科コンサルトが必要な状況である。血液内科的には IgG 上昇・新規骨病変のため再燃を疑い，M 蛋白・FLC・CRAB・全身画像で再評価し全身治療の変更/開始および骨修飾薬を並行管理する。**T11 が不安定性の主体**（高度圧壊＋後方成分破壊）であり，T8・T9 を UIV，T12・L1 を LIV とする bridge fixation でT10・T11をまたぐ後方固定術を計画する。T7（後壁温存）は固定範囲外で BKP を施行し，疼痛コントロールを図る。T11 への BKP は後方成分破壊のため禁忌。MM 多発溶骨性病変・ステロイド歴による骨質不良が予測されるため，UIV・LIV へのセメント充填スクリューを前向きに検討する。術後は硬性 TLSO 装着，骨修飾薬継続，放射線科との RT 協議，血液内科との全身治療継続を並行して進める。

## 紹介状用まとめ

多発性骨髄腫に伴う T7・T10・T11 病的骨折の患者さんです。SINS スコア高値（Unstable）であり T11 を不安定性の主体と判断しております。T8・T9–T12・L1 の bridge fixation（後方椎弓根スクリュー固定）でT10・T11をまたぐ手術を計画しております。T7（後壁温存）は BKP を施行し疼痛コントロールを図ります。T11 は後方成分破壊のため BKP 禁忌です。UIV・LIV へのセメント充填スクリューを使用予定です。血液内科にて MM 全身治療・骨修飾薬を並行管理いただいており，術後の放射線治療についても放射線科と協議中です。ご高診のほどよろしくお願いいたします。
